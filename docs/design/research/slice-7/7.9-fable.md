## 1. The host call

**1a. One permutation, three doors.** The runtime's
`precompile::poseidon2_compress` (`pvm/runtime/src/precompile.rs:296-313`)
is the function on bytes: decode sixteen little-endian words, refuse any
`≥ P` (so `P` itself), `vos_pvm_poseidon2::permute`, the first eight words
out. The proof's tracer now calls exactly it (`Poseidon2Op::compress`,
`tracing.rs:50`), and the guest shim's `WHAT` fallback
(`precompiles/src/poseidon2.rs:34-55`) builds the same state with
`M31::new`, which asserts `value < P` ("an M31 word is below p",
`field.rs:21`), then `permute`. The agent's inner-machine serving
(`machines.rs:514-535`) pre-checks the sixteen words itself and then calls
the shim, so its own `0x402` can never trap the agent, and on JAM the
shim's fallback is what runs. So every door reaches one `permute` on words
each proven below p; the cross-host tests (`precompile_agreement`, the
testkit's `an_actors_poseidon2_call…`, the reference tree on both hosts)
are the confirming measurement.

**1b. The input checks and the trap.** φ7/φ8 above `u32` refuse
(`u32::try_from(...).ok()?`); `read_bytes_checked` needs `PERM_RO` on
every page of the 64 bytes and `write_bytes_checked` `PERM_RW` on the 32,
and `range_has_at_least` (`memory.rs:448-461`) uses `checked_add`, so a
range wrapping the address space refuses rather than reads page 0. The
output is computed before anything is written, so a refused call writes
nothing (the output may overlap the input, tested at `0x1000` and
`0x1020`). On the refine host a `None` is `PANIC` on the call's own counter
(`refine_host.rs:271-277`; the test asserts `pc == 10` on the interpreter
and the recompiler), after the price was charged, as BLAKE2b's is; the
tracer does the same (`tracing.rs:300-307`); the agent returns
`Failure::Trapped` before any write. An unpayable call stops out of gas
unserved on all three (the charge precedes `execute`). This is pin H as
written.

**1c. The kernel exclusion holds at three fences.** `is_kernel_call` is
now `BLAKE2B_COMPRESS | WITNESS_INPUT` (`precompile.rs:86-88`), and
`derive` refuses statically any `ecalli` id outside it in a kernel's blob
(`compiler/src/derive.rs:846-856`), so a kernel linking the shim is
refused at install, not at run time. `surface::kernel` was the whole
precompile range and is now the same two ids, tied to `is_kernel_call`
over the range by the hosts test; the agent's kernel loop serves
`BLAKE2B_COMPRESS` alone (`kernel.rs:92-94`, the `Exit::Host(_)` fall-through
is `Trapped`); the tracer's `is_proof_host_call_allowed` excludes
`ECALL_POSEIDON2` and `serves` adds it only under `with_poseidon2`
(`tracing.rs:123-126`), so a node segment's tracer ends a run at it and its
charge no longer runs for an unserved id (the `self.serves(id)` change at
`:281` is right: an unserved call must not pay a VOS price). Format 35 is
untouched. The one thing not tested by name is a kernel ELF that calls
`0x402` being refused by `derive` (L5).

**1d. Gas and serving, deterministic.** The actor pays
`price(0x402) = 2,400` plus its `ecalli` block on both hosts (3,121
measured, equal on VOS and JAM, asserted). The agent's meter takes
`precompile::serving(id)`, `POSEIDON2_SERVING = 60,000`, on every host; the
real outer cost is 5,756 on VOS (the bounce plus the host's 2,400) and
38,630 on JAM (the bounce plus the software permutation), both under the
test's four-fifths bound, so a batch metered on VOS never runs out of real
gas on JAM. The work result carries the metered figures only, so the
reference test's byte-equal results on both hosts are the right check. The
workflow path prices the written page at φ8's 32 bytes
(`units.rs:275-276`), correct by inspection and untested (the record says
so; L3).

## 2. The tree

**2a. Tags and domain separation.** `Tag::word` pins the six `t`
(`credentials.rs:104-113`) and the test recomputes each from
`BLAKE2b-256("vos/p2/" ‖ name)[0..4] & 0x7fff_ffff` reduced, distinct and
nonzero, with the domain shown to be one BLAKE2b input (not a key). A leaf
is `C(T(leaf), m)`, a node `C(l, r)`, the empty leaf eight zeros; since
`t ≠ 0` the tag block never equals `E_0`, and the path is fixed at 32
levels from a leaf, so no internal node can be presented as a leaf: the
only way to a foreign leaf is a second preimage of `C`. The slot is not
hashed and the path places it, as §8 pins.

**2b. Empty subtrees and deletion.** `EMPTY` (33 blocks) is pinned and the
test rebuilds each level from the one below. `write`
(`credentials/src/lib.rs:274-310`) removes a row equal to its level's
empty subtree and inserts otherwise, at every level including the root
(level 32, index 0), and `node` falls back to `EMPTY[level]` for a missing
row, so a revocation that empties a subtree deletes its nodes up to where
a sibling is non-empty, and the reference (which keeps only non-empty
nodes) agrees after twelve random batches. Each parent is computed once
(`parents.contains_key`), the sibling taken from `changed` when both
children moved, else from storage: 33 calls an enrollment, 32 a revocation,
535 for 256 contiguous slots, as recorded.

**2c. Paths.** `path` serves sibling `(level, (slot >> level) ^ 1)` and
the root from the `(32, 0)` row; `root_of` walks `slot >> level & 1`
(`credentials.rs:497-507`), the bit convention §8 states; `Path::proves`
refuses any word `≥ p` in the member, the root or a sibling before
walking, and the reference's own walk agrees on every member of every
batch. `Siblings` encodes as exactly 1,024 bytes, no length, and a short
buffer fails to decode.

**2d. Slots: reuse, fresh, and no sharing.** `place` takes `free.first()`
(the lowest, since `u32` keys encode big-endian and `Ordered` iterates in
key order, `table.rs:55-58`) and removes it, else `next` (refusing `Full`
past `u32`); `revoke` moves a slot from `slots` to `free` and `count`
down. A slot is in `free` only after a member left it and in `slots` only
after it left `free` or `next`, which never decreases, so two members
never hold one slot, and `admit` refuses a member already in `slots`, so
one member never holds two. `enroll_many` takes fresh slots only
(`place(member, false)`), the record's reason being gas, and refuses a
duplicate within the call because `place` inserts into `slots` as it goes
and the next `admit` sees it; the handler's `Err` is `host::fail`
(`sdk-macros/src/messages.rs:753`), whose writes are discarded (core model
§8, "a callee's own error, whose writes are discarded"), so "one fails,
none enrolled" rests on the step model, and the refusals test checks
`count == 1` and no path for the half-enrolled member after it.

**2e. Invite and claim.** `invite` requires a digest, refuses an enrolled
member, and overwrites a standing invitation; `claim` is any caller,
refuses `NotInvited` before touching the tree, `Expired` strictly after
`expires_ms` (inclusive, tested at `6,000` against `6,000` and `5,999`),
then enrolls through the same `place`, which drops the invitation; a
second claim is `Enrolled`. `revoke` withdraws an invitation of a member
not enrolled. An interceptor of a claim can only enroll the digest it
names, and holds no `s`. The two refusals are ordered so a malformed
member is `NotADigest` before `NotInvited` (tested for `invite`; the same
`admit` runs first in `claim`).

**2f. The ring and `ROOT_MAX_AGE`.** `Ring::record` replaces the newest
entry's root at an equal batch time and appends otherwise, dropping past
64; `accepts` finds the root's *latest* entry (`rposition`), accepts the
newest unconditionally and a superseded one while `time − next.since ≤
ROOT_MAX_AGE` (saturating, so a replica behind the superseding batch
accepts it too). `found` writes the empty tree's root from its batch time
and every write records, so the ring is one entry a batch that changed the
tree, as pin G says. A root that recurs (enroll then revoke) is judged by
its later entry, which is right: a root commits to a tree, and the tree is
in that state again. The same-time replacement (the record's L4) is
liveness only and in the direction of safety: the dropped root is the one
*without* the later batch's revocation, and a client holding it is told
`Unknown` and refetches. Nothing lets a non-member obtain a path, a
revoked member keep one past `ROOT_MAX_AGE` of its revocation's batch at
every replica, or two members share a leaf.

**2g. Role gating.** `found`, `enroll`, `enroll_many`, `invite`, `revoke`
are `role = "registrar"` (checked by the agent against the caller's
member row, `invocation.rs:173-176`, `Forbidden` before the handler runs),
`claim` and the four queries any caller; every write but `found` is behind
`founded()`, and `found` is once and never zeros. As §6 pins.

## 3. The price

The bench pairs the two natively on one loaded machine (1M calls each):
Poseidon2 at 2.6–4.4 times BLAKE2b's TSC cycles, and the price is four
BLAKE2b prices, so the ratio is taken at its loaded upper end, which errs
toward over-pricing the call. The absolute (~1,800 cycles quiet) is an
estimate from BLAKE2b's quiet 520, not a quiet measurement (L4). For
denial of service the question is whether 2,400 gas buys more than 2,400
gas' worth of node time anywhere: natively no (≤ 1.5 cycles a gas even at
the loaded figure); through the agent the batch's meter pays 60,000 a
served call against 5,756 real on VOS, so serving is bounded at about
16,600 calls a 1 GiB refine, an enrollment 33 of them; the shim's software
path costs the guest 37,585 of its own gas. `enroll_many(256)` at 78.3M of
its 100M is registrar-only and its cost is the rows (a put 64,000), not the
hashes (~100,000 of 535 calls). `path` costs 33 reads under the query
limits, any caller; that is the general query surface's exposure, which
7.11's node credential surface and its rate limits inherit (note 3).

## 4. The deferrals

Safe. The schema mark, the system row and `Failure::Credentials` are how
ingress and refine *find* the actor; in 7.9 nothing looks for it, so
their absence changes nothing an attacker can use. The φ8 page pricing is
right by inspection and one workflow test away (L3). The same-time ring
replacement is the pinned rule and liveness only (2f); 7.11's ingress
should map `RootRefusal::Unknown` to a retryable code so a client refetches
its path (hand-off 1). One thing the record does not say that 7.12 should
know: the ring's 64 entries bound freshness in practice for a busy space
(64 writes inside ten minutes make an honest root `Unknown` before
`Stale`), so the library's refresh timer should be well under 64 batches'
worth (hand-off 2).

## 5. Code quality

Where it matters it is good: one `poseidon2_compress` for the runtime and
the tracer, the tree in the wire where ingress will read it, the actor
311 lines with one `write`. Small things: the agent's word check
duplicates the shim's (the shim could expose a checked
`poseidon2_compress_block` returning `Option`, L6); `Table::first` treats
a truncated key as `None` but a truncated value as a trap (`.ok()?` then
`.expect`, `table.rs:212-214`), and a 64-byte first buffer holds about ten
`free` rows where one was meant (harmless, L6); the counter's `compress`
hashes zeros for a wrong-length argument (test actor, fine). The anchoring
race fix (`412949dd`) accepts any `to != leader`, weaker than "a listed
replica" (L1).

## Findings by severity

**Low**
- **L1.** `anchoring.rs:455-466`: the loosened assertion checks
  `to != leader`, not that `to` is listed; assert membership in the listed
  set.
- **L2.** 7.11's ingress must treat `RootRefusal::Unknown` as retryable
  (refetch the path), since the same-time replacement and the 64-entry
  bound both produce it for an honest member; say so in the 7.11 entry's
  prerequisites.
- **L3.** No workflow exercises the φ8 page pricing (`units.rs:275`): one
  workflow test calling `0x402` with its output on an unwritten page.
- **L4.** The absolute native cost is an estimate; one quiet `precompile
  native` run (seconds) would pin it beside the ratio.
- **L5.** No test derives a kernel ELF that calls `0x402` and sees
  `DeriveError::HostCall`; `a_kernel_reaching_an_unknown_id_is_refused`
  covers an unknown id, not this one.
- **L6.** The shim could carry the checked block compression the agent
  needs; `Table::first`'s two decode failures should agree.

**Notes (no action)**
- `Ring::record` at an equal batch time drops the safer-to-drop root (2f).
- The ring's count bounds freshness for a busy space; 7.12's refresh
  period should be set with that in mind (§4).
- `path` by any caller is the query surface's exposure, to be rate-limited
  with the rest at 7.11's node credential surface.

## Verdict

**Merge.** The call is pin H on every host with one permutation behind it
and the kernel fences in place; the tree is §8's and §6's, checked against
a from-scratch reference on both hosts; the prices are measured and err
safe. L1–L6 at will; L2 and the freshness note go to 7.11 and 7.12.
